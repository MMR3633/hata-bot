# Хата: закрытый хаб на двоих (дизайн)

Дата: 2026-11-13. Утверждено Расулом в чате («газуй»).

## Цель

Один закрытый Telegram-бот с Mini App для двух человек (Расул 111111111, Лера @friend 222222222):
Майнкрафт на ноуте, блок-дуэль на время, совместный просмотр видео, позже общий экран (Neko).

## Состав

```
Telegram ──► бот «Хата» + Mini App  (bothost.ru, аккаунт palfboom, один процесс: aiogram + aiohttp + SQLite)
                  │ WebSocket /ws: дуэль, кино
                  │ HTTPS long-poll /api/agent/*
                  ▼
         агент на ноуте (Python) ──► Paper (Minecraft Java) в C:\Users\USER\HataMC
                                         ▲
                        друг ──Radmin VPN (сеть с паролем)──┘
```

Код: `C:\Users\USER\Hata`. Публичный репозиторий без секретов (bothost тянет из GitHub).

### Модули хаба (`hub/`)

| Файл | Что делает |
|---|---|
| `config.py` | читает env: BOT_TOKEN, ALLOWED_IDS, AGENT_TOKEN, YT_API_KEY, PORT, DATA_DIR, PUBLIC_URL |
| `auth.py` | проверка initData (HMAC, auth_date < 24 ч), белый список, токены сессий, одноразовые ссылки для ПК |
| `db.py` | SQLite: sessions, pc_links, duel_games, duel_results, agent_cmds, agent_state |
| `duel.py` | движок блок-игры: генерация фигур по seed, проверка хода, подсчёт очков (сервер = судья) |
| `rooms.py` | комнаты WebSocket: дуэль (лобби, старт, ходы, таймер, итог), кино (состояние плеера, чат, реакции) |
| `search.py` | поиск видео: YouTube Data API v3, RuTube открытый поиск, разбор ссылок YT/RuTube/VK |
| `agent_api.py` | очередь команд для агента ноута, статус Майнкрафта |
| `web.py` | aiohttp: статика Mini App, /api/*, /ws |
| `bot.py` | aiogram: /start (кнопка Mini App), /pc, /mc, чужим тишина |
| `main.py` | запуск бота и веба в одном цикле |

Mini App: `webapp/index.html` + `webapp/js/*.js` (vanilla JS), вкладки Майн, Дуэль, Кино, Счёт.

### Агент ноута (`agent/`)

`agent.py`: опрашивает хаб, выполняет команды, шлёт статус каждые 15 с.
Команды: `start`, `stop`, `create_world {name, seed, type}`, `switch_world {name}`, `backup`, `list_worlds`.
Сервер: Paper 26.3 (последний stable на 13.11.2026), Java 25 (Temurin JRE в `HataMC\java`), `-Xmx3G`, RCON на 127.0.0.1 для статуса и команд.
Датапак высоты собирается из ванильного `dimension_type/overworld.json` внутри jar Paper (формат в 26.x другой, руками не писать).

## Правила

### Доступ
- Только ALLOWED_IDS. Чужим бот не отвечает, API отдаёт 403.
- initData → токен сессии (7 дней) → заголовок `Authorization: Bearer` и параметр `?t=` у WebSocket.
- `/pc` в боте → ссылка `PUBLIC_URL/?pc=<код>`, код одноразовый, живёт 10 минут.
- Агент ходит с AGENT_TOKEN (env на хабе и `.env` на ноуте).

### Блок-дуэль
- Поле 8×8, лоток из 3 фигур, новый лоток когда все 3 поставлены.
- Набор фигур: 1, 2, 3, 4, 5 в линию (обе ориентации), квадраты 2×2 и 3×3, уголки 2×2 и 3×3 (4 поворота), T, S, Z, L (повороты).
- Генератор: детерминированный PRNG mulberry32 от seed, одинаковый в Python и JS.
- Очки за ход: число клеток фигуры + за сгорание `10 × линий × линий` (1 линия 10, 2 линии 40, 3 линии 90) × множитель серии.
- Серия: ход со сгоранием увеличивает серию на 1, множитель = 1 + 0.5 × (серия − 1); три хода подряд без сгорания сбрасывают серию.
- Раунд 180 с от общего старта. Нет ни одного возможного хода → игрок закончил, ждёт.
- Сервер принимает ход `{tray_index, row, col}`, проверяет, применяет, рассылает счёт и поле сопернику. Ход после конца раунда отклоняется.
- Итог: победа, ничья. История в `duel_results`, рекорды на вкладке Счёт.

### Кино
- Состояние комнаты: `{src: yt|rutube|vk, id, playing, pos, at}`; любой участник управляет.
- Клиент подстраивается, если расхождение больше 2 с.
- Поиск: YouTube (нужен YT_API_KEY, без ключа вкладка просит вставить ссылку), RuTube. VK только по ссылке.
- Чат (последние 50 сообщений в памяти) и реакции-эмодзи поверх видео.

### Майнкрафт
- `online-mode=false`, `white-list=true` (ники Расула и Леры), `enforce-whitelist=true`.
- Новый мир: барьер 500×500 (`worldborder set 500`), датапак высоты: overworld min_y −64, height 512.
- Бэкап: zip папки мира в `HataMC\backups`, хранить последние 5 на мир.
- Сеть: Radmin VPN, адрес сервера показывается на вкладке Майн (`MC_ADDRESS` в .env агента).
- Ноут не прислал статус 45 с → Mini App показывает «ноут спит».

## Ошибки
- Нет сети у хаба до Telegram: aiogram сам переподключается.
- WebSocket оборвался: клиент переподключается с бэкоффом, комната отдаёт полное состояние при входе.
- Агент не достучался до хаба: повтор каждые 5 с, сервер Майнкрафта продолжает работать.
