# Хата Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline). Steps use checkbox (`- [ ]`) syntax.

**Goal:** закрытый бот @hata_duo_bot с Mini App (Майн, Дуэль, Кино, Счёт) на bothost и агент Майнкрафта на ноуте.

**Architecture:** один процесс Python на bothost (aiogram 3 polling + aiohttp веб и WebSocket + SQLite в /app/data). Mini App на vanilla JS. Агент на ноуте ходит к хабу long-poll'ом по AGENT_TOKEN и управляет Paper через subprocess и RCON.

**Tech Stack:** Python 3.13, aiogram 3.31, aiohttp, sqlite3, pytest; JS без сборки; Paper 1.21.x, Java 21; Radmin VPN.

Спека: `docs/superpowers/specs/2026-11-13-hata-design.md`.
